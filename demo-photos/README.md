# Фотографии для демонстрационных объявлений

Положите сюда снимки инструмента — **свои, с телефона**, а не стоковые.

    demo-photos/
      perforator.jpg
      bolgarka.jpg
      ...

Затем:

    $env:SUPABASE_SECRET_KEY="sb_secret_..."; npm run demo:fill

Скрипт загрузит их в Storage и создаст восемь объявлений в каталоге под
отдельным демонстрационным владельцем. Убрать — `npm run demo:clear`.

## Почему свои, а не стоковые

Студийный снимок инструмента в каталоге про Кокшетау виден мгновенно: он
сообщает «здесь ничего настоящего нет». Фотография из гаража работает
наоборот — она выглядит как вещь, которую человек и правда возьмёт.

Хватит шести-восьми штук. Снимайте при дневном свете, целиком, без
обрезанных краёв: те же снимки станут доказательством состояния вещи,
если дойдёт до спора о порче.

## Что попадёт в репозиторий

Сами фотографии — нет, они в .gitignore. Только этот файл: снимки могут
весить много, а публичный репозиторий им не нужен.
